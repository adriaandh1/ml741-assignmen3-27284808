# ML741 Assignment 3

This repository contains the code, results, and report for my third Machine
Learning 741 assignment. The experiment compares ordinary all-class training
with fixed and adaptively growing minority-first incremental neural networks on
Dry Bean, Landsat, and Optical Digits.

The final report is [`27284808RW741assignment3.pdf`](27284808RW741assignment3.pdf).

## Quick start

Python 3.12 is the reference version.

```bash
make setup
make test
make smoke
make report
```

`make smoke` runs a small synthetic end-to-end example. Use a different output
folder on later runs, for example `make smoke SMOKE_OUTPUT=results-smoke-2`.

## Full reproduction

The published summaries and figures are already included. To repeat the full
experiment from the original UCI data:

```bash
make data
make final-runs
make analysis
make sensitivity
make report
```

The full run is intentionally not part of the default target because it trains
90 models. Downloaded data, checkpoints, and per-run predictions are ignored by
Git; they are regenerated by these commands.

The reusable implementation is in `src/ml741_assignment3`, executable scripts
are in `scripts`, frozen settings are in `configs`, and the report source is in
`report`.
